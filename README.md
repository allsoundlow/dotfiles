# dotfiles

Personal shell configuration, managed with [GNU Stow](https://www.gnu.org/software/stow/).

## Structure

```
zsh/                    # stow package
├── .zshrc              # loader
├── .zprofile           # PATH and login-shell env
└── .zsh/
    ├── .p10k.zsh       # powerlevel10k config (generated by `p10k configure`)
    ├── plugins_before.zsh
    ├── settings.zsh
    ├── aliases.sh
    ├── prompt.zsh
    ├── external.sh     # nvm, conda, bun
    ├── plugins_after.zsh
    └── plugins/        # third-party clones, not tracked
```

Load order matters. `plugins_before.zsh` adds to `fpath` and must run before
`compinit` in `settings.zsh`. `plugins_after.zsh` sources zsh-syntax-highlighting,
which wraps every ZLE widget defined above it and must therefore run last.

## Setup on a new machine

```sh
git clone https://github.com/allsoundlow/dotfiles.git ~/dotfiles
cd ~/dotfiles

brew bundle --file=Brewfile     # packages + MesloLGS Nerd Font
./install.sh                    # clones plugins, runs stow
```

Then set the terminal font to **MesloLGS NF** (Ghostty picks it up from
`ghostty/config` automatically; iTerm2 and Terminal.app need it set manually).

## Third-party plugins

Not tracked in this repo — they are separate git repositories. `install.sh`
clones them into `~/.zsh/plugins/`:

| Plugin | Repo |
|---|---|
| zsh-syntax-highlighting | `zsh-users/zsh-syntax-highlighting` |
| zsh-autosuggestions | `zsh-users/zsh-autosuggestions` |
| zsh-completions | `zsh-users/zsh-completions` |

Manual install, if needed:

```sh
mkdir -p ~/.zsh/plugins
for p in zsh-syntax-highlighting zsh-autosuggestions zsh-completions; do
    git clone --depth=1 "https://github.com/zsh-users/$p" ~/.zsh/plugins/$p
done
```

## Local overrides

`~/.zshrc.local` is sourced at the end of `.zshrc` if present, and is
deliberately **not** in this repo. It holds machine-specific and
work-infrastructure settings (instance IDs, internal hostnames, relative
`node_modules/.bin` PATH entries).

See `zsh/.zshrc.local.example` for the expected shape.

## Stow usage

```sh
cd ~/dotfiles
stow -nv zsh      # dry run — shows what would be linked
stow zsh          # create symlinks
stow -D zsh       # remove them
stow -R zsh       # restow (after adding new files)
```

## Notes

- Prompt is [powerlevel10k](https://github.com/romkatv/powerlevel10k), installed
  via Homebrew. The project is in maintenance mode but stable.
- Re-running `p10k configure` writes to `~/.p10k.zsh`, not to the repo copy at
  `~/.zsh/.p10k.zsh`. Move it manually afterwards.
- `conda config --set auto_activate false` is required, otherwise conda adds
  ~900ms to shell startup and duplicates the prompt's env segment.
- Startup time check: `time zsh -i -c exit` (target: under 250ms).
  Profile with `zmodload zsh/zprof` at the top of `.zshrc` and `zprof` at the
  bottom.
